# Release Notes — Agent Eyes v0.9.0

**Target release:** 2026-07-21 after final approval
**Owner:** Jelly Thomas
**Strategy:** All-at-once immutable PyPI release through GitHub Trusted Publishing

---

## TL;DR

Agent Eyes v0.9.0 makes foreground, browser-neutral computer use the default:
it inventories and reuses relevant open tabs before opening a new one, keeps
background browser control behind explicit shadow consent, replaces fixed
orchestration waits with event-driven completion plus bounded watchdogs, and
adds a guided, dependency-aware setup flow. The release also hardens provider
thread affinity, observation identity, concurrency, reconnect cleanup, output
bounds, and cross-platform packaging.

## What's new

- **Native-first browser targeting.** Accessibility-visible tabs from Safari,
  Firefox, Chromium-family browsers, and other accessible browsers are ranked
  and reused without requiring a Chrome remote-debugging restart.
- **Guided first-time setup.** `agent-eyes setup` checks dependencies,
  permissions, the persistent launcher, MCP configurations, and skill files,
  then presents one user-approved change plan.
- **Event-driven completion.** Native and explicit shadow waits finish when the
  expected state is observed; bounded adaptive checks are retained only as a
  watchdog when an event subscription is unavailable.
- **Qualified observations.** Snapshot tokens bind actionable element IDs to
  provider, mode, target, connection generation, and document revision.

## What's fixed

- **Repeated remote-browser prompts.** Normal browser work no longer probes or
  requests a background Chrome session; shadow access is explicit.
- **Duplicate browser scans.** Concurrent tab inventories share one native
  accessibility scan instead of queuing identical provider work.
- **Provider waiter retention.** Timed-out or cancelled calls are unlinked even
  when an operating-system provider remains hung.
- **Persistent-CDP reconnect residue.** Reconnects retire stale sessions, tabs,
  handlers, domains, and pending commands without disturbing newer generations.
- **Unbounded CDP DOM fan-out.** Node description work uses a connection-wide
  bounded worker pool.
- **Protected upload path aliases.** File injection now canonicalizes protected
  roots, rejects case and symlink aliases, detects hard-link identity, and
  fails closed on filesystem comparison errors.

## What's changed (behavior / API)

- **Browser policy:** foreground native automation is the default. A new tab is
  opened only after no suitable existing target can be reused.
- **Shadow tools:** `web_tree`, `js`, `dialog`, `upload`, and `pierce` require
  explicit `shadow=true`; target-based shadow tools also require a stable
  `target_id` from `list_tabs(shadow=true)`.
- **Element actions:** tools that consume prior observations require the
  corresponding snapshot token where target identity cannot otherwise be
  proven.
- **Readiness:** capability checks are execution-plane specific. A missing
  physical-input backend no longer disables read-only native inspection, and a
  missing native provider no longer disables explicit CDP work.

## What's deprecated

None.

## What's removed

- Runtime dependency installation from MCP startup/tool calls. Use
  `agent-eyes setup` in a terminal instead.
- Implicit background-browser fallback during normal foreground browser work.

## Upgrade / migration steps

- [ ] Upgrade with `uv tool upgrade agent-eyes` or `pipx upgrade agent-eyes`.
- [ ] Run `agent-eyes setup --repair` to verify providers and refresh supported
  MCP/skill configuration.
- [ ] Restart each changed MCP client so it reconnects through the persistent
  launcher and reloads the skill.

## Known issues

- Linux/Wayland physical input depends on compositor/session support and is not
  universal; `doctor` reports the gap.
- Native accessibility can only expose the tab metadata and page structure a
  browser publishes to assistive technology. Exact inactive-tab URLs or DOM
  data may require an explicitly requested shadow provider.
- OS accessibility permissions still require user action and may require
  restarting the responsible launcher application.

## Rollback notes

- Previous version: 0.8.0
- Rollback path: yank 0.9.0 on PyPI, install `agent-eyes==0.8.0` with the active
  tool manager, restart MCP clients, and open a corrective patch release. PyPI
  artifacts are immutable and will not be overwritten or deleted.
- Rollback window: immediate; this release has no data or schema migration.
